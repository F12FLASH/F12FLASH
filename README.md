## 👨‍💻 About Me

**Hello, I'm F12FLASH! 👋**

**Coder by day, Security Explorer by night.**

I live in the world of code and firewalls. As a Full Stack Developer, I enjoy turning ideas into dynamic web applications. But with the mindset of a cybersecurity enthusiast, I always ask myself: "How can I break it?".

The name **F12FLASH** isn't just a name. It represents the combination of **F12** (the developer tool) and **FLASH** (speed, decisiveness). That is my philosophy: develop quickly, but always ready to "flash" into potential weaknesses to protect the product.

**Things I often "tinker" with:**

*   ⚛️ Building smooth front-ends with React.
*   🚀 Building solid back-ends with Node.js.
*   🔍 Scanning and security testing applications.
*   🛡️ Learning about the latest attack techniques to understand how to defend.
